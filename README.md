# 🔥 Build a Cozy Pixel-Art Campfire Landing Page with HTML, CSS & JavaScript

> "Some people build portfolios. We built a campfire."

Welcome! 👋

In this tutorial, we'll build a cozy pixel-art landing page inspired by late-night coding sessions, campfires, and retro games.

Instead of creating another to-do app, we'll create a website that tells a story through a terminal interface, pixel art, and a peaceful campsite.

By the end of this tutorial, you'll have:

- 🔥 An animated campfire
- 💻 A developer terminal with a typing animation
- 🐶 Juno, the sleepy dog
- 📱 A responsive landing page
- ✨ Interactive terminal commands

---

# 🚀 What You'll Learn

In this project you'll learn how to:

- Build a webpage using HTML
- Style a modern landing page with CSS
- Organize project files
- Create a terminal UI
- Make a typing animation using JavaScript
- Handle button interactions
- Build a responsive layout

No frameworks required.

Just HTML, CSS and JavaScript.

---

# 🛠 Prerequisites

You'll only need:

- Basic HTML
- Basic CSS
- Basic JavaScript
- VS Code
- A modern browser
